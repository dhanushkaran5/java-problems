# Java Problems

A curated collection of Java programming challenges, algorithmic puzzles, and interview preparation questions. This repository serves as a centralized log to practice problem-solving, track progress, and learn clean coding practices using modern Java features.

---

## 🚀 Repository Structure

The project is organized by topic and difficulty to make navigation effortless:

```text
java-problems/
├── src/
│   ├── data_structures/     # Arrays, LinkedLists, Stacks, Queues, Trees, Graphs
│   ├── algorithms/          # Sorting, Searching, Dynamic Programming, Greedy
│   ├── leetcode/            # Targeted LeetCode solutions
│   └── hackerrank/          # Targeted HackerRank challenges
└── README.md
```

Each problem file contains:
* The core solution class.
* Comprehensive unit tests or a `main` method showcasing test cases.
* In-line documentation detailing the time and space complexity (O(N) notation).

---

## 🛠️ Prerequisites & Setup

Ensure you have the following installed on your local machine:
* **Java Development Kit (JDK):** Version 17 or higher is recommended.
* **Build Tool:** Maven or Gradle (Optional, for dependency management).
* **IDE:** IntelliJ IDEA, Eclipse, or VS Code with Java Extension Pack.

### Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory:**
   ```bash
   cd java-problems
   ```
3. **Compile and run a specific solution:**
   ```bash
   javac src/algorithms/YourSolution.java
   java src/algorithms/YourSolution
   ```
